## 版本 A：完整旁白（约 3 分钟，可直接做 TTS）

**【0:00–0:12｜开场】**
一个分子能不能反应、走哪条路、快还是慢，答案常常藏在一个叫"过渡态"的结构里。
但今天，AI 可以在几秒钟内画出一个看起来很像过渡态的三维结构。
问题是——**看起来像，不等于它是。**

**【0:12–0:45｜问题】**
过去两年，生成式模型让过渡态候选的产量提高了几个数量级：给它一张二维分子图和几个反应原子，它就能吐出三维猜测。
可是一个候选结构要成为"可发表的过渡态"，必须同时满足：恰好一个虚频、虚频指向你声明的那根键、两端连到你想要的反应物和产物、电子态一致。
这四件事，生成模型一件都不保证。
而在催化体系里，一个错误的过渡态足以把两条机理的先后顺序整个颠倒，甚至凭空造出一条不存在的通道。

**【0:45–1:05｜方案】**
这个项目提出的不是又一个生成模型，而是**生成之外的那一层：验证**。
它的原则只有一句话：**AI 提议，物理筛选，DFT 验证，人来决定。**
流程被拆成五道关卡——P0 到 P4，每一步都有明确的通过条件和明确的失败出口。失败不是重跑的理由，失败是数据。

**【1:05–1:55｜五道关卡】**
第一关，化学预检：写清五个声明——哪根键成、哪根键断、电荷与自旋面、连通性、参考态；再用一个保守的过滤器把硬重叠和错连通挡在门外。
第二关，势垒区扫描：不用一次跑完的集体扫描，而是每一个点一个独立作业。实测里，一个 16 点的剖面被集体扫描毁掉三次，改成逐点之后 **16/16 全部收敛**。
第三关，约束参考点加频率：产出两样东西——一个可以单独交差的参考点，和一份解析 Hessian。
第四关，把这份 Hessian 喂给 OptTS。**复用 Hessian 是整个流程里最大的一次可靠性提升**：没有它，优化器会沿着错误的模式爬几百个周期。
第五关，终检：一个虚频、模式是否命中声明的反应对、关键键长、IRC 两端连到谁、自旋诊断、能量口径——六项逐一过。

**【1:55–2:25｜实测教训】**
这些不是纸上推演，是踩出来的。
有一次，沿虚频方向把结构挪了 0.18 埃——听起来很温和，但那个模式里重原子也在动，真正要断的键一下变了 0.31 埃，优化跑了 183 个周期，一路滑进反应物盆地。
把位移改成"目标键长变化 0.05 埃"之后，结构才稳稳落在鞍点邻域。
还有一次，同一个点始终有两个虚频，两轮位移都回到同一个几何、能量只差 0.003 kcal/mol——流程给的不是"再试一次"，而是"停，按宽平谷如实报告"。

**【2:25–2:50｜新能力与边界】**
0.2 版加入了一个可选的加速层：用基础机器学习势在 DFT 之前做几何修复和候选分诊。
但我们把边界写在了明处：五个 DFT 已验证的破缺对称单重态鞍点，全部落在它的势能面之外，被判为"势能面不匹配"；只有一个真实的极小点被正确判为盆地。
所以它的定位是**修几何的急救包**，不是判过渡态的裁判。

**【2:50–3:05｜交付与结尾】**
整个流程被做成一个可移植的开源技能包：本地 ORCA 与 xtb，超算 Gaussian 与 Slurm；核心脚本只依赖 Python 标准库，不需要深度学习环境；输入显式、无隐藏状态、上下游文件缺失就停。
它不承诺替你发现机理，它承诺让每一个过渡态**经得起追问**。
仓库地址在屏幕下方。AI 提议，物理裁决。

## 版本 B：30 秒短视频口播

AI 几秒钟就能画出一个过渡态，但它是不是真的？
这个开源项目只做一件事：**验证**。
五道关卡——化学预检、逐点扫描、约束参考加 Hessian、OptTS、六项终检；一个可选的机器学习势加速层，边界写在明处。
实测：16 点剖面在集体扫描失败三次后做到 16/16；0.18 埃的错误位移让优化 183 轮跑进反应物盆地——这些坑都变成了流程里的停机规则。
**AI 提议，物理裁决。** 仓库在简介里。

## 事实核对表（做字幕时用）

- 流程：五道必需关卡 P0 化学预检 → P1 逐点势垒扫描 → P2 约束参考点 + Hessian → P3 OptTS（复用 Hessian）→ P4 六项验证；外加一个可选加速层 P0.5
- 逐点扫描：16 点剖面，集体扫描失败 3 次后 16/16 收敛
- 位移教训：最大原子位移 0.18 Å → 反应键变化 −0.31 Å → 183 个周期进入反应物盆地；改成目标键变化 0.05 Å
- 高阶鞍点：两轮位移回到同一几何，能量差 0.003 kcal/mol
- 生成模型分布外：4 个候选过筛，但重原子 RMSD 3.6–4.4 Å
- 构象主导：R/S 配体叠合 RMSD 1.62 Å
- MLIP 预筛：5 个 DFT 验证鞍点全部 83–85 kcal/mol 不匹配；1 个极小点正确判盆地；不省 DFT 周期（ORCA 在首轮前即投影约束，3.000 → 2.150 Å）
- 体系规模：50–120 原子，Ni/Fe 催化
