## 版本 A：完整旁白（约 3 分 20 秒，可直接做 TTS）

**【0:00–0:15｜开场】**
AI 现在几秒钟就能算出一个分子的性质、画出一条反应路径、给出一个过渡态。
速度快了三个数量级，但有一个问题没解决：**算出来的东西，凭什么信？**
这个项目做的不是更快的计算，而是让计算**可信**。

**【0:15–0:45｜问题】**
生成式模型让过渡态候选的产量提高了几个数量级：给它一张二维分子图和几个反应原子，它就能吐出三维猜测。
可一个候选要成为"可发表的过渡态"，必须同时满足：恰好一个虚频、虚频指向你声明的那根键、两端连到你想要的反应物和产物、电子态一致。
这四件事，生成模型一件都不保证。而在催化体系里，一个错误的过渡态足以把两条机理的先后顺序整个颠倒。
问题不在算得慢，在于**没有人替结果把关**。

**【0:45–1:05｜定位】**
所以这是一套**验证优先**的工具箱：AI 提议，物理筛选，DFT 验证，人来决定。
它的核心功能是找过渡态——五道关卡，P0 到 P4；但同一套关卡和规则，也直接服务于反应能、键能、构象和自旋态这些日常计算。
换句话说：**它不止会找 TS，它管的是一整条"从结构到可信数字"的路。**

**【1:05–1:55｜核心：五道关卡】**
第一关，化学预检：写清五个声明——哪根键成、哪根键断、电荷与自旋面、连通性、参考态；再用一个保守的过滤器把硬重叠和错连通挡在门外。
第二关，势垒区扫描：不用一次跑完的集体扫描，而是每个点一个独立作业。实测里，一个 16 点的剖面被集体扫描毁掉三次，改成逐点后 **16/16 全部收敛**。
第三关，约束参考点加频率：产出一个可以单独交差的参考点，和一份解析 Hessian。
第四关，把 Hessian 喂给 OptTS。**复用 Hessian 是整个流程里最大的一次可靠性提升**：没有它，优化器会沿错误的模式爬几百个周期。
第五关，终检：一个虚频、模式是否命中声明的反应对、关键键长、IRC 两端连到谁、自旋诊断、能量口径——六项逐一过。

**【1:55–2:35｜不止 TS：同一套关卡的其他用法】**
**反应能与键能。** 键解离自由能、反应热，用的是同一套"约束参考点 → 频率 → 高一级单点"的阶梯；真正容易错的不是算，是口径——优化、频率、单点必须同级，极小点和鞍点之间只能用电子能 ΔE 比，SMD 的 CDS 约定必须全程一致，破缺对称的单点必须继承 UKS、MORead、FlipSpin。混一个口径，垒就能偏五到十一 kcal/mol。这些规则都写成了检查项。
**构象。** 先用机器学习势把柔性链折一遍，再进 DFT；做 R/S 比较之前必须先做构象系综——我们实测过，两个"非对映体"的配体叠合差有 1.62 埃，比立体中心本身的差别大得多。
**自旋态。** 含金属体系先枚举所有可及自旋面，每个面分别算，报数时带 ⟨S²⟩——同一个几何换个自旋设置，可能就是另一个电子态。
**几何与作业。** 重叠检查、连通性核对、MLIP 预优化、输入生成、超算提交、输出核验——这些不性感的活在每一类计算里都要做，工具把它们做成了一道道闸门。

**【2:35–2:55｜实测教训】**
这些不是纸上推演，是踩出来的。
有一次，沿虚频方向把结构挪了 0.18 埃——听起来很温和，但那个模式里重原子也在动，真正要断的键一下变了 0.31 埃，优化跑了 183 个周期，一路滑进反应物盆地。
把位移改成"目标键长变化 0.05 埃"之后，结构才稳稳落在鞍点邻域。
还有一次，同一个点始终有两个虚频，两轮位移都回到同一个几何、能量只差 0.003 kcal/mol——流程给的不是"再试一次"，而是"停，按宽平谷如实报告"。

**【2:55–3:15｜边界与形态】**
加速层：用基础机器学习势在 DFT 之前做几何修复、构象折叠和候选分诊。
但我们把边界写在明处：五个 DFT 已验证的破缺对称单重态鞍点，全部落在它的势能面之外；只有一个真实的极小点被正确判为盆地。所以它是**修几何的急救包**，不是判过渡态的裁判。
整个工具箱可移植：本地 ORCA，超算 Gaussian 与 Slurm；核心脚本只依赖 Python 标准库，学习势层单独装一个 torch 环境；输入显式、无隐藏状态、上下游文件缺失就停。

**【3:15–3:25｜结尾】**
它不承诺替你发现机理，它承诺让每一个数字**经得起追问**——不管这个数字是过渡态、键能，还是一句话就能说清的反应热。
仓库地址在屏幕下方。AI 提议，物理裁决。

## 事实核对表（做字幕时用）

- 核心：五道必需关卡 P0 化学预检 → P1 逐点势垒扫描 → P2 约束参考点 + Hessian → P3 OptTS（复用 Hessian）→ P4 六项验证；外加可选加速层 P0.5
- 同一套关卡的其他用途：反应能 / 键解离自由能（约束参考点 + 频率 + 高一级单点）、构象系综、自旋态枚举、几何修复、作业编排与输出核验
- 能量口径：优化/频率/单点同级；极小点 vs 鞍点只用 ΔE；SMD 的 CDS/色散约定全程一致（混用可让垒偏 5–11 kcal/mol）；BS 单点继承 UKS+MORead+FlipSpin
- 逐点扫描：16 点剖面，集体扫描失败 3 次后 16/16 收敛
- 位移教训：最大原子位移 0.18 Å → 反应键变化 −0.31 Å → 183 个周期进入反应物盆地；改成目标键变化 0.05 Å
- 高阶鞍点：两轮位移回到同一几何，能量差 0.003 kcal/mol
- 构象主导：R/S 配体叠合 RMSD 1.62 Å
- MLIP 预筛：5 个 DFT 验证鞍点全部 83–85 kcal/mol 不匹配；1 个极小点正确判盆地；不省 DFT 周期（ORCA 在首轮前即投影约束，3.000 → 2.150 Å）
- 体系规模：50–120 原子，Ni/Fe 催化
