# 加速过渡态寻找与优化：五段协议（P0–P4）

> 来源：2026-09/10 `S_H2-orca` 与 `双自由基手性` 两个项目的实测记录。
> 适用：**已知基元步骤**、约 50–120 原子、有机/有机金属、单参考 DFT 级别。
> 不适用：未知机理的自动发现（走 GOAT-TS / UniTS-Gen / 多通道枚举）、强多参考/激发态/非绝热/自旋翻转、界面与传质控制。
>
> 一句话：**把“失败”前移到便宜的计算；把 Hessian、构象、自旋变成可复用资产；用定量止损线替代“再跑一次”。**

---

## 1. 四段流程（P0–P4）

```
P0 化学定义与预筛 ──► P1 垒区定位 ──► P2 约束参考点+Hessian ──► P3 OptTS ──► P4 验证
   (0.5–2 h)          (1–20 h)          (2–6 h)                 (4–12 h)      (2–6 h)
```

### P0 化学定义与预筛（最便宜，省掉大部分 DFT 浪费）

必须写清楚，缺一项就不要提交 DFT：

- **反应对**：哪几对成键、哪几对断键；每对在起始几何里的实际距离（> 4 Å 的“反应对”通常是错的）。
- **电荷、多重度、自旋面**：含金属体系按 dⁿ 枚举所有可及自旋态（如 d⁷ 双峰/四重态，d⁸ 单重态/三重态），外加 BS 破缺对称解；**每个面各找一遍**，不要默认某一个面。
- **连通性核对**：用 `1.3×(r_i+r_j)` 建键图，逐键核对“计划中的键是否还在、有没有计划外的新键”。项目里三次事故（1,2-酰基迁移、酮加成重排、enc6 自发闭环）都是这一步没做。
- **构象搜索**：柔性配体/长链先用 `mlip_tools.py conf`（机器学习势）生成 16–64 个随机旋转异构体，在 MLIP 面上松弛并按 RMSD 去重，保留 3–5 个低能构象；没有 MLIP 环境就用 ORCA GOAT 或其它构象生成器。**R/S 或底物比较必须先做这一步**；否则差值可能是构象主导（实测 RMSD 1.62 Å，单构象数字不可报）。
- **模型截断检查**：把旁观基团换成 Me/Et 或截短长链后，反应中心几何、电荷、自旋是否保持；用全尺寸模型抽检一次。
- **对比完整性**：任何 R/S、底物或自旋面之间的比较，提交前 **diff 两边输入**。约束值、溶剂、泛函、基组、格点、`MaxIter` 必须同值，只允许手性/取代基/自旋不同。项目里出现过 R/S 约束被写成 2.13/2.39 vs 2.08/2.42 的口径 bug，两条曲线严格说不在同一约束面上。
- **候选预筛**：`ts_prefilter.py` 查硬重叠、clash、Kabsch RMSD、连通性差异；把 DFT 时间花在值得的结构上。

### P1 垒区定位（不要盲冲 OptTS）

目的只是找到 TS 初猜，不是拿能量结论。

1. **MLIP 松弛扫描**（可选，秒–分钟级）：`mlip_tools.py scan` 快速看势垒大概在哪、是否单调、有没有浅鼓包。MLIP 数值只用于排布，**不进正文**；BS 单重态/自旋翻转体系不在其适用域内。
2. **DFT 逐点独立 Opt**（推荐；4–8 点）：沿反应坐标取点，每点一个独立的 `! Opt` 作业，`MaxIter 220`，距离约束；每点从**上一点的收敛几何**接续。伪代码：

```text
prev = reactant.xyz
for d in [2.05, 2.36, 2.68, 2.99, 3.31, 3.62, 3.94, 4.25]:
    write inp:
        ! Opt TPSS D3BJ def2-SVP RIJCOSX SMD(Toluene)
        %geom
          MaxIter 220
          Constraints
            { B i j d C }        # 反应坐标
            { B k l d2 C } ...   # 需要保持的框架约束
          end
        end
        * xyzfile charge mult prev.xyz
    run orca
    if output contains "THE OPTIMIZATION HAS CONVERGED":
        record E, d, key bond lengths
        prev = job.xyz
    else:
        mark failed; keep prev; continue   # 不要让一个点拖垮整条曲线
```

**不要用 ORCA 的 `%geom Scan` 做这件事**：ORCA 6.1.1 里扫描任意一点撞 `MaxIter` 会连环收尾失败，整条扫描报废（本项目实测 3 次）。逐点独立作业的代价只是多几个输入文件，换来的是单点失败不连坐——r2 进攻剖面 16/16 全收敛，两次弄死扫描的 R 点 1 也只用了 44 周期。

3. **只信收敛点**：解析时认 `CONVERGED` 标志；未收敛点的能量不能进曲线，最多用来判断“是不是平坦面”。
4. **取最高收敛点**作为 TS 初猜；同时保留整条曲线，检查是否单调、是否有多个浅鼓包（多构象/多通道的信号）。

### P2 约束参考点 + Hessian（必做，且永远有产出）

在 P1 最高点对应的反应坐标值上做：

```text
! Opt Freq TPSS D3BJ def2-SVP RIJCOSX SMD(Toluene)
%geom
  MaxIter 220
  Constraints
    { B i j d C }
    ...
  end
end
```

产出两样：`.hess`（P3 的 `InHess Read` 要用）和模式谱（诊断用）。

**门禁 P2（不过就不进 P3）**：

- 最低几个模式是否牵动声明的反应对？
  - **是** → 进 P3。
  - **否** → 约束点最低模不是你的反应坐标，`InHess Read` 会把优化器带上错模式。改约束值/换构象/换方位重做 P2，或直接换初猜来源。
- 约束点本身是“约束参考点”，不是 TS；即使 P3 失败，它也是可用的相对比较基准。**先拿到参考点，再追真 TS——这个顺序让工作永远有产出。**

### P3 OptTS 精修（Hessian 复用是核心）

```text
! OptTS Freq TPSS D3BJ def2-SVP RIJCOSX SMD(Toluene)
%geom
  MaxIter 120–300
  InHess Read
  InHessName "<P2>.hess"
end
* xyzfile charge mult <P2>.xyz
```

要点：

- **必须 `InHess Read`**。ORCA 6.1.1 的 `OptTS` 默认用 Almlöf 模型 Hessian 的最低模起步；柔性大体系会沿错模式上坡磨满 `MaxIter`。这是本项目 66 小时实测换来的铁律。
- **MaxIter**：柔性/软模体系 120–160；刚性体系 220–300。不要用“加大 MaxIter”掩盖起点错误。
- **模式位移**（第一次 OptTS 落到错误驻点，或需要离开二阶鞍点时）：
  - 取目标虚频的本征向量，反质量加权成笛卡尔位移。
  - **按“目标键长的变化量”定标，不要按“最大单原子位移”定标。**
  - 目标键长变化取 **0.05 Å** 量级（例如 Cβ–H 1.400 → 1.315，Ni–H 1.750 → 1.804）。
  - 实测反例：按最大原子位移 0.18 Å 定标时，H 只动 0.18 Å，但 Cβ 和 Cα 各动 0.17/0.19 Å，Cβ–H 实际从 1.400 掉到 1.093 Å（−0.31 Å），**直接越过鞍点扎进反应物盆地**，183 周期单调下降。
  - 位移后仍读 P2 的 Hessian；不要重新生成模型 Hessian。
- **未收敛兜底**：ORCA 的 `OptTS Freq` 在优化不收敛时**直接终止、不算频率**。要么留足 `MaxIter`，要么对末态几何单独补一个 `Freq` 作业，再判断驻点性质。
- **不要反复重启同一几何**：如果能量单调下降 > 50 周期且反应键不变，说明起点在错误盆地；停，回 P1/P2。

### P4 验证与止损（决定能不能报数）

按顺序过：

1. **虚频数**：恰 1 个显著虚频（< −20 cm⁻¹）。
2. **模式定域度**：转移原子占位移总量的百分比。真 TS 约 40%；`< 15%` 且前几名落在“最大位移的 0.5–0.7 倍”平台区 ⇒ 离域软模，不是反应坐标。
3. **几何自洽**：把关键键长读出来，逐个对照“该还在的键/该断的键/该成的键”。**SADDLE-1 + 命中反应对 ≠ 找到目标 TS**；P2 的 `−1363 cm⁻¹` 鞍点就是 Ni–Cα 已断（3.712 Å）、羰基 O 回配（1.971 Å）的烯醇化通道。
4. **连通性**：首选 IRC both（从收敛 TS 几何出发，读 P3 的 `.hess`）；约束与 IRC/NEB 不兼容。便宜替代：从 TS 几何做 `! Opt`（不是 `OptTS`）向下弛豫，看落到哪个极小点，再逐键核对。
5. **自旋**：⟨S²⟩ 与 Mulliken 自旋；BS 单重态约 0.2–0.4，不是 0。高一级单点必须继承 `UKS + MORead + moinp + FlipSpin + FinalMs`，否则 ORCA 默认 RKS，算出闭壳层单重态。
6. **能量口径**：极小点 vs 鞍点比较用 **ΔE**（鞍点虚频被排除在配分函数外，ΔG 不可比）；同一类型内才用 ΔG；单点级别 ≥ 优化级别；SMD/CDS 校正全链一致。
7. **报告**：方法、基组、色散、溶剂、自旋面、虚频、模式定域度、IRC 端点、⟨S²⟩、误差来源。构象主导的 R/S 差值必须附构象搜索说明。

## 2. 五个加速杠杆（带实测证据）

| 杠杆 | 做法 | 实测证据 | 省什么 |
|---|---|---|---|
| **Hessian 复用** | P2 约束 `Opt+Freq` → P3 `InHess Read` | 无 Hessian 的自由 `OptTS` 沿 Almlöf 模型 Hessian 漂移，磨满 300 周期 | 省 10–50 h 的无效爬坡 |
| **逐点独立 Opt 替代 Scan** | 每点一个 `! Opt`，距离约束，几何接续，`MaxIter 220` | ORCA 6.1.1 扫描任一点撞 `MaxIter` 整条报废（实测 3 次）；逐点方案 16/16 收敛 | 省整条扫描重跑（20–40 h） |
| **小位移 + 目标键长定标** | 目标键长变化 0.05 Å，不是最大原子位移 | 0.18 Å 最大位移导致 Cβ–H 变化 −0.31 Å，183 周期扎进反应物盆地 | 省 5–10 h 的错误 OptTS |
| **便宜预筛前移** | 构象搜索、连通性、clash、自旋枚举、反应对距离 | 三次重排事故、R/S 构象主导（RMSD 1.62 Å） | 省掉在错误结构/错误自旋/错误构象上的全部 DFT |
| **定量止损** | 见 §3 | 六元环 TS 两轮位移都滑回同一鞍点（能量差 0.003 kcal），第三轮无意义 | 省 10–20 h 的重复失败 |

## 3. 十条止损规则（看到就停，不要“再跑一次”）

| # | 判据 | 动作 |
|---|---|---|
| 1 | P2 约束点最低模不牵动反应对 | 不进 P3；改约束/构象/方位 |
| 2 | OptTS 能量单调下降 > 50 周期且反应键不变 | 起点在错误盆地；停，回 P1/P2 |
| 3 | 两次位移 OptTS 收敛到同一几何/能量（差 < 0.01 kcal），软模仍在 | 停；不要第三次。接受并披露 / 换刚性模型 / IRC 沿反应模 |
| 4 | 2–3 个 −15…−25 cm⁻¹ 浅虚频 | 宽平过渡谷；用末态 Freq 作参考能垒并写明“参考能垒” |
| 5 | 虚频模式定域度 < 15% | 离域软模，不是目标反应坐标；换初猜/换约束 |
| 6 | SADDLE-1 + 命中反应对，但关键键长不对 | 错误通道；回 P1/P2，不能报该反应能垒 |
| 7 | MLIP 与 DFT 结论冲突 | 以 DFT 为准；MLIP 只用于修复、折叠与预筛 |
| 8 | IRC/弛豫端点不是目标反应物/产物 | 回 P1/P2；不要报能垒 |
| 9 | 单点 ⟨S²⟩ 与几何作业不一致 | 电子态错了；补 `UKS/MORead/FlipSpin` 重算 |
| 10 | R/S 差值未做构象搜索 | 不能当立体选择性；先做构象系综 |

补充：**二阶鞍点的处理**。若恰有一个大虚频（反应模）+ 一个小的旁观软模（配体扭转/骨架摆动），且软模在 `DefGrid3` 下仍存在，说明它是真实的第二条负曲率，不是格点假象。三条路：(a) 接受并披露“沿旁观软模有二阶鞍点特征”，用反应模的能垒并说明；(b) 换刚性模型（tBu→Me/Et）消掉软模，整套重算；(c) IRC 沿反应模验证连通性。不要指望“再推一次”能修好——本项目两轮都滑回同一鞍点。

## 4. 路线决策树

| 体系/信息 | 首选路线 | 备注 |
|---|---|---|
| < 60 原子、有机、闭壳层 | UniTS-Gen 多采样（10 个）→ 预筛 → P2–P4 | 论文单次 42% 正确，多采样后 5/5；不要单次定论 |
| 60–100 原子、有机金属、BS 面 | 手搭 + P1 逐点扫描 + P2–P4 | UniTS-Gen 在本项目 84 原子 BS 体系实测不可用（4 个 PASS 的 RMSD 3.6–4.4 Å）；手搭反而最稳 |
| > 100 原子、柔性配体 | 先截断/简化模型 + 构象搜索；P1 逐点扫描 | 不要指望 ML 生成；先问“截断后机理是否不变” |
| 未知机理/多通道 | GOAT-TS 或手动枚举反应位点 | GOAT 零安装、物理严格，但 100+ 原子 BS 体系很慢；多通道各自走 P2–P4 比较 span |
| 只有反应物和产物、无 TS 猜测 | 先 P1 扫描或 GOAT，不要直接 OptTS | 直接 OptTS 的失败率最高 |
| 激发态/非绝热/自旋翻转 | 不在本协议范围 | 需要 MECP/非绝热动力学，单面 TS 不够 |

## 7. 常见反模式（不要做）

- 盲目加大 `MaxIter` 或换大基组来“修”不收敛。
- 从同一几何反复重启 `OptTS`，期待不同结果。
- 用 Almlöf 模型 Hessian 跑柔性大体系的 `OptTS`。
- 用 ORCA `%geom Scan` 做长剖面；一个点失败拖垮整条。
- 按“最大原子位移”做模式位移；应按目标键长变化定标。
- 只看 `SADDLE-1` 和“命中反应对”，不读关键键长。
- 用 MLIP 能量下结论；它只做修复、预折叠与预筛。
- 单点作业丢掉 `UKS/MORead/FlipSpin`，把 BS 几何算成闭壳层。
- 没做构象搜索就把 R/S 单构象差值当立体选择性。
- 把二阶鞍点/宽平谷的“约束参考点”当一阶 TS 报。

## 8. 与现有脚本的衔接

- `ts_prefilter.py`：P0 候选预筛（clash / RMSD / 连通性）。
- `ts_ladder.py`：生成 P2→P3→P4 的四个作业（`L1-constOptFreq`、`L2-TSopt`、`L3-relax`、`sp-L2-TS`）。
- `ts_ladder_run.py`：串行执行 + 逐级门禁 + 按诊断路由。
- `ts_verify.py`：P4 虚频计数、虚频牵动原子、IRC 判读。
- `ts_scan_pts.py`：P1 的逐点独立扫描生成器/执行器（ORCA）。每个点一个 `! Opt` 作业，
  失败点跳过、从上一个收敛点接续、只统计 `CONVERGED`、自动汇总 `scan_summary.tsv`。
- `gauss_ts_prep.py` / `gauss_verify.py`：同一协议的高斯/Slurm 版本（L1→L2→IRC→SP）。

### 8.1 ORCA 与 Gaussian 的对应写法

| 协议步骤 | ORCA 6.1 | Gaussian 16 |
|---|---|---|
| P1 逐点扫描 | `! Opt` + `%geom Constraints { B i j d C }`，每点独立作业 | `opt=modredundant` + `B i j d F`，每点独立作业 |
| P2 约束参考点 + Hessian | `! Opt Freq` + 同一约束；产出 `<job>.hess` | `opt=(calcfc,modredundant) freq`；Hessian 写入 `.chk` |
| P3 OptTS 读 Hessian | `! OptTS Freq` + `InHess Read / InHessName` | `opt=(ts,readfc,noeigen) freq` + `geom=check guess=read`（`%oldchk` 指向上一步） |
| P4 IRC | `! IRC` + `%irc InitHess Read / Hess_Filename / Direction both` | `irc=(readfc,maxpoints=N,stepsize=N)` + `geom=check guess=read` |
| P4 高一级单点 | `! <method2> <basis2>` + `* xyzfile` TS 几何 | `#p <method2>/<basis2> geom=check guess=read` |
| 虚频/模式判读 | `ts_verify.py`（含模式投影） | `gauss_verify.py`（计数/终止/热化学）；模式归属用 `freq=hpmodes` + GaussView |

⚠️ 高斯 `ReadFC` 要求 `.chk` 里已有解析 Hessian；若没有，退回
`opt=(ts,calcfc,noeigen)`（重算 Hessian，慢但稳）。ORCA 的 `InHess Read` 同理，
`.hess` 必须来自同一几何的 Freq 作业。

## 9. 这套方法的边界

它加速的是“已知要什么 TS”的**执行**，不是“知道该找哪个 TS”的**发现**。如果机理本身没定（竞争通道、自旋面、构象、质子化态），再好的 OptTS 协议也只是更快地找到错的点。所以 P0 的化学判断和 P4 的连通性验证不能省；这两步才是“加速”不会变成“加速犯错”的原因。
